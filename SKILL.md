# Resume Tailoring Skill

Use this skill when tailoring `resume.tex` to a specific job description stored in `JD.txt`.

## Workflow

1. Read `JD.txt` and identify the target role, required skills, preferred qualifications, and repeated keywords.
2. Update `resume.tex` so the summary, skills, experience bullets, and projects emphasize the strongest truthful matches.
3. Keep bullets concise, impact-oriented, and quantified where possible.
4. Preserve the LaTeX structure unless a layout change is explicitly requested.
5. Compile `resume.tex` into `resume.pdf` after edits.

## Quality checklist

- The resume is one page unless the user asks otherwise.
- The summary is tailored to the job description.
- Skills include relevant keywords from the job description.
- Experience bullets start with strong action verbs.
- Claims remain truthful and are not invented beyond user-provided facts.
